## Phase 5 — "Next Level" roadmap (deferred, build only after v1 fully ships and is stable)

This is the blown-out, ambitious version of the idea. **Do not start any of this until every box above is checked and v1 is deployed and working.** Sequencing matters more than ambition here — a shipped v1 with this roadmap documented is a stronger portfolio artifact than an unfinished attempt at all of this at once.

- [ ] **Git time-travel**: timeline scrubber over commit history — buildings rise on file creation, grow/shrink with LOC changes over time, disappear on deletion, districts emerge as folders are created. Requires walking git log history (via GitHub API or a shallow clone) and replaying tree snapshots at intervals rather than just the current HEAD.
- [ ] **Live dependency roads**: parse imports (real AST-based parsing this time — e.g. via a lightweight parser per language, starting with JS/TS) and draw glowing connection paths between buildings on click. Color-code: imports vs imported-by vs circular dependency. Only render on-demand (per selected building), not all connections at once.
- [ ] **Code Health mode**: a toggle that re-colors the entire city by a computed health score (complexity + coupling + staleness) instead of language — healthy=green, risky=amber/red, dead code = visibly abandoned/overgrown buildings. Requires a proper complexity metric, not just the regex proxy from v1.
- [ ] **Landmark buildings**: compute an "importance score" (incoming imports + commit count + contributor count) and give the top few files unique landmark treatment (central tower, city-hall-style entry point building, etc.) instead of generic archetype shapes.
- [ ] **Search + fly-to**: search bar for filename → smooth camera flight to that building.
- [ ] **Guided city tour**: scripted/templated camera flythrough hitting the most important districts/landmarks with generated captions (template-based first; LLM-generated narration as a stretch goal after that works).
- [ ] **Achievements/discoveries** (optional, lower priority, purely for fun/shareability): badges like "Ancient Ruin" (file untouched N years), "Spaghetti Junction" (circular dependency detected), "Megacity" (LOC threshold).

Explicitly out of scope even long-term (these belong to a different project, "Git City," not this one): user accounts, social features, a persistent multiplayer world, payments/shop, leaderboards across users.
